# CodeAlpha Frontend Development Internship Tasks

This repository contains the projects I completed as part of my **CodeAlpha Frontend Development Internship**. During this internship, I successfully developed three front-end web applications using **HTML**, **CSS**, and **JavaScript**. These projects helped me strengthen my understanding of responsive web design, DOM manipulation, JavaScript logic, and modern UI development.
